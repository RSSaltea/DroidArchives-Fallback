# Droid portraits

Added on 21 September 2026, with transparent backgrounds. Animated lighting is not included.

- `protocol/{SA-5,LOM,PZ,TDA}_{Gold,Diamond,Rainbow,Beskar,Galactic,Stellar}_v2.png`: 24 complete, collected-state portraits, including the material layers that supply Rainbow colour, Galactic detail and the Stellar effect. These replace the incomplete canvas-only exports.
- `kyber/*_Kyber.png`: 83 green Kyber portraits, including the four Protocol droids, stored for release. There are no separate Inactive, Blue or Purple portraits.

The Protocol portraits are mapped in `data/droids.json`. The Kyber files are stored as assets only and are not connected to the app.
