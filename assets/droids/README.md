# Droid portraits

Source: https://droidex.dubtrackr.win/droid-tycoon-droidex/

Saved on 21 September 2026 from Droidex's rendered portrait canvases, with transparent backgrounds. Animated lighting is not included.

- `protocol/{SA-5,LOM,PZ,TDA}_{Gold,Diamond,Rainbow,Beskar,Galactic,Stellar}.png`: 24 portraits, replacing the Default-image placeholders for these finishes.
- `kyber/*_Kyber.png`: 83 green Kyber portraits, including the four Protocol droids, stored for release. The source does not supply separate Inactive, Blue or Purple portraits.

The Protocol portraits are mapped in `data/droids.json`. The Kyber files are stored as assets only and are not connected to the app. Existing images outside these files retain their previous sources.
