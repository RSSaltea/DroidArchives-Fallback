Droid Archives Companion

A Windows app that watches for droid spawns, keeps your blueprint timers, and puts the Archives and Optimise pages over the game.

Download for Windows Portable — no installer
This is an open beta — expect bugs.

It is still being actively worked on, and things do break between versions. If something misbehaves, it is far more likely to be the app than anything you did.

The app keeps an activity log of everything it does. Open it from Overview → Activity log and send it over on Discord — that log is usually what makes a bug findable.

What it does

  • Alerts you when a droid spawns, filtered by quality and rarity
  • Blueprint countdowns for Mythic, Beskar and Galactic
  • CB23 Mission and Rebirth Droid alerts
  • Optional notifications to your phone, so you get alerts with the game closed
  • The Archives and Optimise pages as panels over the game, sharing your login

Getting started

  • Run the exe — there is no installer, and it does not need admin
  • Windows may warn about an unrecognised app. Choose More info → Run anyway.
  • Fortnite works best in Windowed Fullscreen. Exclusive fullscreen can hide overlays.
  • In Spawn alerts, use Select on screen to draw a box around the chat area where spawn messages appear.

Keys

The overlay never takes your mouse unless you open a panel yourself, so panels open by key. The game does not receive these presses.

F8Droid Archives panel
Alt + OOptimise panel
F9Quick settings over the game

More keys — clearing the recent-spawns list, adding a droid to your Droidex — can be set in Overview → Keyboard shortcuts.
